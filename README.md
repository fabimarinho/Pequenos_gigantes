# Pequenos Gigantes

Protótipo acadêmico de um aplicativo educativo sobre doação de órgãos infantis. O projeto apresenta informações em linguagem simples e acolhedora, com o objetivo de apoiar a compreensão do processo e facilitar conversas em família.

## O que o protótipo apresenta

- Boas-vindas e menu de conteúdos;
- Explicação sobre doação de órgãos e tecidos;
- Seções interativas de mitos e verdades e perguntas frequentes;
- Visão geral das etapas do processo;
- Sugestões para conversar em família;
- Favoritos salvos no navegador;
- Links para consultar fontes oficiais;
- Layout responsivo para computador e celular.

## Tecnologias

O site foi desenvolvido com HTML, CSS e JavaScript, sem dependências ou processo de compilação.

## Como abrir

Abra o arquivo `index.html` em um navegador. Para publicar, envie os arquivos do projeto para um repositório GitHub e conecte esse repositório à Vercel como um site estático.

## Observação importante

Este é um protótipo acadêmico e tem finalidade exclusivamente educativa. Não substitui orientação médica ou informações fornecidas pela equipe de saúde. Antes de qualquer uso público, revise o conteúdo com profissionais responsáveis e confira se as fontes oficiais continuam atualizadas.
